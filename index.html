How to choose

  1. Open all three designs.
  2. Reply with the number you prefer: Design 1, 2 or 3.
  3. You can also mix, for example "Design 2 layout with Design 3 colors".
  4. Send any changes: logo, prices, sizes, more photos.

Every design includes

  • Logo and menu
  • Opening section with headline, intro, buttons and photos
  • Ready-to-wear, custom tailoring and fabrics
  • All 12 products with size, USD price and an Order on WhatsApp link
  • Custom tailoring section
  • Footer with WhatsApp number

How to build it in GoHighLevel

Every design uses only basic GoHighLevel blocks: sections, rows, columns, Headline, Paragraph, Image, Button and Nav Menu. No custom code is needed.

  1. Go to Sites, then Websites (or Funnels), and create a new blank page.
  2. In page settings, add the two or three Google Fonts for the chosen design and set the page background color.
  3. Upload the 12 product photos from the ghl-images folder to the Media library. They are already cropped to the same 3:4 size, so the product grid lines up.
  4. Build the sections from top to bottom using the build table, colors and sizes in that design's specification below.
  5. Check the mobile view. GoHighLevel stacks columns on phones automatically.
